# 🥗 DietPal - Mobile Diet Assistant

DietPal ek light-weight, responsive aur user-friendly Web Application UI hai jo users ko unki daily calories, macros (Protein, Carbs, Fat) aur water intake track karne me help karta hai.

---

## 📱 Features

* **Dashboard View:**
  * **Daily Progress Bar:** Total calories aur macro-nutrients ka visual progress.
  * **Water Tracker:** Interactive water glass counter.
  * **Today's Meals:** Din bhar me khaye gaye khano ki list aur calories details.
* **Meal Plan & Custom Meals:** Din ke meal plan dekhne aur custom meal add karne ka UI layout.
* **Food Database/Search:** Common food items aur unki calorie count dekhne ke liye search bar.
* **Goals Management:** Daily target calories aur macros set karne/update karne ka option.
* **Interactive UI:** Dynamic tab switching aur smooth CSS animations.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure ke liye.
* **CSS3:** Custom styling, CSS Variables (`:root`), Flexbox aur Mobile-first Responsive design ke liye.
* **JavaScript (ES6):** Tab navigation, water tracker toggle aur dynamic calorie progress update ke liye.
